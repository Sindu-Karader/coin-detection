# Coin Detection System

A web-based Indian coin detection system built using Python, TensorFlow/Keras, EfficientNetB0, and Flask. The system allows users to upload a coin image and predicts the corresponding coin denomination.

## Technologies Used

- Python
- TensorFlow / Keras
- EfficientNetB0
- Flask
- HTML
- CSS
- JavaScript

## Features

- Upload an Indian coin image
- Process the image using a trained deep learning model
- Predict the coin denomination
- Display the prediction through a web interface
